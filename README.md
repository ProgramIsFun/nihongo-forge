# Nihongo Forge

A Japanese learning website to help you master hiragana, katakana, kanji, vocabulary, and grammar.

## Features

- Interactive kana learning (Hiragana & Katakana)
- Vocabulary drills with spaced repetition
- Grammar lessons and practice
- JLPT preparation (N5–N1)

## Tech Stack

- React 19 + TypeScript
- Vite

## Getting Started

```bash
git clone git@github.com:ProgramIsFun/nihongo-forge.git
cd nihongo-forge
npm install
npm run dev
```
